# 旧回放重置插件

## 解决什么问题？

用于处理 **AgentRouter Responses 旧会话无法继续聊天** 的资源绑定错误：重置影响续聊的旧回放状态，**保留原聊天记录**。
是否适用于其余公益站有待验证。
是否可解决其余问题也有待验证，部分场景下测试无问题。

## 典型报错

在原会话发送消息失败，错误信息中出现：

```text
The requested item was created under a different Azure OpenAI resource
```

意思是：旧回放条目属于另一个上游资源，与当前接口不匹配。这类问题可能在接口或上游资源变更后出现。

## 怎么操作？

1. 打开发生报错的**原会话**，等待当前运行和相关子任务结束。
2. 在**输入框下方、模型选择旁**点击 **“重置旧回放”**。
3. 看到操作完成的提示后，在原会话重新发送消息，继续聊天。

点击本身**不会发送聊天消息、删除历史、切换模型或重跑工具**。如果提示“结果未确认”，先点“重试检查”核验状态，不要连续点击重置。

> 适用范围：DSH core `0.2.2-rc.1` 的 AgentRouter Responses 会话。余额不足、密钥无效、网络故障等问题不属于本插件的处理范围。
